## 使用方式

1. 克隆或下载本仓库。
2. 从 `stickers/` 中选择需要的 PNG 文件。
3. 在聊天软件、文档、演示或社团内容中使用。

建议保留文件名，以便通过文字快速检索表情含义。`无文字.png` 可作为没有文字覆盖的基础形象，用于海报、活动物料或符合许可的衍生设计。

## 关于社团

电子科技大学成都学院开放原子开源社团以计算机技术、软件开发与开源实践为主要方向，致力于在校园传播开源文化、组织开源活动、参与开源项目并培养开源人才。社团围绕 OpenTenBase、OpenHarmony、openEuler 等方向开展学习与实践，连接校园同学与开源社区。

- 社团官网：[kcos.net.cn](https://kcos.net.cn/)
